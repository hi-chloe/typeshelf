## Adding a screenshot

One screenshot of the app is plenty. Run `npm run dev`, click **Load 3 sample fonts**,
select Tinos so the specimen is legible, and capture the window at a normal desktop size.
Save it here, then add one line under the intro paragraph in `README.md`:

```markdown
![Typeshelf showing a font specimen with size, spacing, and color controls](./docs/images/typeshelf.png)
```

Keep the alt text describing what's visible rather than repeating the filename, and keep
the file under ~500 KB — README images ship with every clone.

A dark-mode shot alongside it is a nice second addition, not a requirement.
